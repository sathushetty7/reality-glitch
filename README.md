# Reality Glitch

https://sathushetty7.github.io/reality-glitch/

> Question reality. Explore perception. Experience the unknown.

Reality Glitch is a cinematic, interactive website experiment that blends reality, perception, design, and code.

The project creates an immersive digital experience with glitch effects, animated sections, interactive buttons, and a reality scan feature.

## Features

- Cinematic dark-themed design
- Glitch-style typography and transitions
- Interactive reality scan
- Animated progress bar
- Anomaly detection experience
- Smooth scrolling navigation
- Reveal-on-scroll animations
- Interactive feature sections
- Responsive layout for different screen sizes
- GitHub link integration

## Technologies Used

- HTML5
- CSS3
- JavaScript
- CSS Animations
- DOM Manipulation
